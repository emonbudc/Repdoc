# Illustration attribution — homepage plates

All files in this folder are the source unDraw illustrations, kept as recolour
references. The homepage inlines theme-adapted copies: ink follows the text
colour, the primary follows the enamel green (`var(--primary)`), paper follows
the surface — so both themes hold with no filters. (Dark-theme adaptation no
longer uses the earlier `invert` experiment.)

- `documents_9rcz.svg` — hero plate — https://undraw.co/illustration/documents_9rcz
- `forms_1ciz.svg` — About plate (PLATE 01) — https://undraw.co/illustration/forms_1ciz
- `no-data_ig65.svg` — empty-state mark — https://undraw.co/illustration/no-data_ig65

projects, **no attribution required**, modification allowed. This file
records the sources anyway so a future operator can re-fetch or replace
