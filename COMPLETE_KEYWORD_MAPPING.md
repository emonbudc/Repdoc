## 1. Mapping rules

1. One primary page per topic and intent.
2. The hub owns generic “সনদ / প্রত্যয়ন” queries.
3. Each guide owns one certificate cluster.
4. Verification is split: explanation page vs lookup page.
5. English/Banglish variants map to the same Bangla canonical unless a real English page is approved.
6. Location variants are not given separate pages.
7. No page targets an official transaction it cannot perform.

## 5. Cannibalisation controls

### 5.1 Hub vs guides

- The hub targets generic “সনদ / সনদ গাইড / প্রত্যয়ন” queries.
- Guides target one certificate name plus modifiers.
- The hub should not repeat every guide’s full checklist.
- Guides should not try to rank for the generic “all certificates” query.

### 5.2 Verification explanation vs lookup

- `/sonod/sonod-verification/` targets informational queries: “সনদ যাচাই কীভাবে”, “QR যাচাই”, “সনদ যাচাই নিয়ম”.
- `/verify/` targets utility queries: “সনদ নম্বর যাচাই”, “certificate verify”.
- Both cross-link, but neither duplicates the other’s job.

### 5.3 Bangla vs English

- Bangla guides are canonical.
- English/Banglish keywords map to the same page unless full English pages are approved.
- If English pages are added, use `hreflang` and self-canonicals.

### 5.4 Location variants

- No separate location pages.
- Location-modified queries map to the national guide.
- The guide explains that the authority depends on the applicant’s address.

### 5.5 Tool landing vs guide

- `/genaretor/certificate/` is for users ready to use the tool.
- `/sonod/` is for users still learning what they need.
- The tool landing links to the guides; the guides link back to the tool.

## 6. Anchor text guidance

Use natural anchors:

- “নাগরিক সনদ গাইড”
- “ওয়ারিশ সনদের কাগজপত্র”
- “চারিত্রিক সনদ ফরম”
- “সনদ যাচাইয়ের নিয়ম”
- “প্রত্যয়ন টেমপ্লেট”

Avoid:

- “এখানে ক্লিক করুন”
- the same exact-match anchor on every page
- keyword-stuffed anchors such as “সেরা নাগরিক সনদ অনলাইন আবেদন ফরম ডাউনলোড”

---

## 8. Maintenance rules

- Update a guide only when the information is actually reviewed.
- Change the visible date and `dateModified` together.
- Remove a mapping if a page is retired; do not leave a 404 in the sitemap.
- Re-check the keyword CSV quarterly.
- Re-check competitor structure quarterly, but do not copy its content.
- Re-validate sitemap count and robots after any registry change.

---

## 9. Bottom line

The mapping is intentionally narrow and honest. Fourteen new URLs cover the strongest certificate queries without creating location spam or fake government services. Existing tool and template pages keep their roles. The next step is measurement, not more mapping for its own sake.
